I want to make a website where I can write down my thoughts and findings using markdown files.
It is just a way to sort my thoughts and if people happen to come across it maybe they can find it useful.
It should also support having embedded pdfs, html, images.
You can also view the git history of the files and switch between different versions of the files. 
For the versions it should show the date and how old I was at that time.
Also a direct diff view should be available to see the changes between the versions.
Should be relatively simplistic and easy to use like a blog or information site viewer.
You can view the folder structure aswell and assign tags to the files for better organization.
You can search files and tags and contents.
There is an about.md file that describes and shows some info and should support some dynamic data like the current date and my age.

I will host the page on cloudflare pages.
The Markdown files will be stored in a public Github repository. The site will read the files from the repo and display them.
My domain is mythoughtsonlife.com. 
If I plan on adding other peoples works there should be a way to switch the repository being read from (preferably a hardcoded list).
